# 艺览 ciTY — 接口文档（首页模块）

> 对应页面：**首页**（轮播图 + 当前热门展览 + 艺览智荐 + 热门美术馆）
> 接口数量：**4 个**（不做聚合接口，前端并行调用）
> 数据库依据：[db/01_create_tables.sql](../db/01_create_tables.sql)、[db/exhibition-表结构说明.md](../db/exhibition-表结构说明.md)、[db/gallery-表结构说明.md](../db/gallery-表结构说明.md)
> 前端联调可配合：[db/04_init_data.sql](../db/04_init_data.sql) 初始化测试数据

---

## 零、统一规范

### 一、响应格式

所有接口统一返回 `Result<T>`：

```json
{
  "code": 1,
  "msg": "操作成功",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `code` | Integer | 1=成功，0=失败 |
| `msg` | String | 提示文案，成功时固定为 `操作成功` |
| `data` | T | 业务数据，失败时为 `null` |

### 二、接口路径规范

- 全部接口强制带 `/api/` 前缀
- C 端：`/api/app/...`
- 首页 4 个接口均为 **C 端公开接口**

### 三、认证规范

| 标识 | 含义 |
|------|------|
| 🔓 | 免登录可访问（首页 4 个接口都是这一类） |
| 🔒 | 必须带 token |

首页接口**全部免登录**。以下路径必须加入 `WebMvcConfiguration` 的 `excludePathPatterns`，否则会被 JWT 拦截器返回 401：

```
/api/app/banner
/api/app/exhibition
/api/app/gallery
/api/app/recommend
```

> ⚠️ 拦截器注册的是 `/api/app/**`，**只放行 `/api/app/login`、`/api/app/register` 是不够的**，首页这 4 个路径必须显式放行。

### 四、JSON 字段命名

- 字段名统一 **camelCase**（小驼峰）
- 数据库字段为 `snake_case`，MyBatis 自动映射（`map-underscore-to-camel-case: true`）
- 日期格式由 `JacksonObjectMapper` 决定：
  - `LocalDate`（数据库 `date`）→ `yyyy-MM-dd`，如 `2026-10-01`
  - `LocalDateTime`（数据库 `datetime`）→ `yyyy-MM-dd HH:mm`
- 金额 `DECIMAL(10,2)` → JSON 数字，如 `58.00`

### 五、首页请求方式

首页**不使用聚合接口**，前端进入页面后**并行发起 4 个请求**：

```
进入首页
  ├── GET /api/app/banner        → 渲染顶部轮播图
  ├── GET /api/app/exhibition    → 渲染「当前热门展览」横排海报
  ├── GET /api/app/recommend     → 渲染「艺览智荐」2×2 宫格
  └── GET /api/app/gallery       → 渲染「热门美术馆」2×2 宫格
```

**好处**：任一区块请求失败或变慢，不影响其余区块渲染（各自独立降级）。

## 一、获取轮播图列表 🔓

- **Path**：`/api/app/banner`
- **Method**：`GET`
- **描述**：首页顶部轮播大图

**参数**：无

**成功返回**：

```json
{
  "code": 1,
  "msg": "操作成功",
  "data": [
    {
      "id": 1,
      "imageUrl": "/static/mock/banner/water-print.jpg",
      "title": "江苏水印木刻实践与研究特展"
    },
    {
      "id": 2,
      "imageUrl": "/static/mock/banner/jiangsu-art.jpg",
      "title": "江苏省美术馆90周年系列展"
    }
  ]
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | Long | 轮播图 ID |
| `imageUrl` | String | 轮播大图地址（**文案已烧入图中**，前端不要再叠字） |
| `title` | String | 标题，**仅供后台识别，页面不展示** |

**失败返回**：

```json
{
  "code": 0,
  "msg": "系统异常",
  "data": null
}
```

**SQL**：

```sql
SELECT id, image_url, title
FROM banner
ORDER BY sort DESC;
```

**数据来源**：`banner` 表

## 二、获取当前热门展览 🔓

- **Path**：`/api/app/exhibition`
- **Method**：`GET`
- **描述**：首页「当前热门展览」横排海报。**必须同时满足「运营标记热门」和「在展期内」两个条件**

**参数**：

| 参数名 | 类型 | 必须 | 默认值 | 说明 |
|--------|------|------|--------|------|
| city | String | 否 | - | 城市筛选，按所属美术馆的城市匹配 |
| limit | Integer | 否 | 10 | 返回条数上限，最大 20 |

**成功返回**：

```json
{
  "code": 1,
  "msg": "操作成功",
  "data": [
    {
      "id": 1,
      "title": "咫尺千里",
      "posterImage": "/static/mock/exhibition/zhichi.jpg",
      "startDate": "2026-09-11",
      "endDate": "2026-12-10",
      "price": 58.00,
      "galleryId": 1,
      "galleryName": "江苏省美术馆",
      "status": "current"
    },
    {
      "id": 2,
      "title": "江苏水印木刻实践与研究特展",
      "posterImage": "/static/mock/exhibition/water-print.jpg",
      "startDate": "2026-09-21",
      "endDate": "2026-11-30",
      "price": 38.00,
      "galleryId": 1,
      "galleryName": "江苏省美术馆",
      "status": "current"
    }
  ]
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | Long | 展览 ID，点击卡片跳详情用 |
| `title` | String | 展览标题 |
| `posterImage` | String | 封面海报 |
| `startDate` / `endDate` | String | 展期，前端拼成 `09.11—12.10` 展示 |
| `price` | Number | 票价（元），`0` 表示免费 |
| `galleryId` | Long | 所属美术馆 ID |
| `galleryName` | String | 美术馆名称（JOIN 取得，**展览表本身没有**） |
| `status` | String | `current` 正在展出 / `future` 即将展出 / `past` 往期展出 |

**失败返回**：

```json
{
  "code": 0,
  "msg": "系统异常",
  "data": null
}
```

**SQL**：

```sql
SELECT e.id, e.title, e.poster_image, e.start_date, e.end_date, e.price,
       g.id AS gallery_id, g.name AS gallery_name
FROM exhibition e
JOIN gallery g ON g.id = e.gallery_id
WHERE e.is_hot = 1
  AND e.start_date <= CURDATE() AND e.end_date >= CURDATE()
  AND (#{city} IS NULL OR g.city = #{city})
ORDER BY e.sort_order DESC, e.id ASC
LIMIT #{limit};
```

**数据来源**：`exhibition` JOIN `gallery`

**注意**：

1. `status` 字段**不落库**，由 Service 层按 `CURDATE()` 实时计算
2. `ORDER BY` 末尾必须带 `e.id ASC` 兜底，否则排序字段有重复值时顺序不确定
3. `galleryName` 靠 JOIN 取得，**不要在循环里逐条查美术馆**（N+1 问题）

## 三、获取「艺览智荐」推荐展览 🔓

> ⚠️ **本接口数据由算法团队提供，不查数据库**
>
> 该模块依赖用户行为数据（浏览、收藏、购票记录）由算法侧实时计算推荐结果。后端不做推荐逻辑，只负责转发参数并把算法返回的展览 ID 补全为完整图文信息。

- **Path**：`/api/app/recommend`
- **Method**：`GET`
- **描述**：返回算法推荐的展览列表，首页取前 4 条铺满 2×2 宫格

**参数**：

| 参数名 | 类型 | 必须 | 默认值 | 说明 |
|--------|------|------|--------|------|
| userId | Long | 否 | - | 当前用户 ID。**未登录时不传**，算法侧返回热门兜底结果 |
| limit | Integer | 否 | 4 | 返回条数 |

**成功返回**：

```json
{
  "code": 1,
  "msg": "操作成功",
  "data": [
    {
      "id": 4,
      "title": "内太空飞行",
      "posterImage": "/static/mock/exhibition/inner-space.jpg",
      "startDate": "2026-10-26",
      "endDate": "2026-12-25",
      "price": 68.00,
      "galleryName": "四方美术馆",
      "recommendReason": "与你近期浏览的当代艺术展相似"
    }
  ]
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | Long | 展览 ID |
| `title` / `posterImage` | String | 卡片展示内容 |
| `startDate` / `endDate` | String | 展期 |
| `price` | Number | 票价 |
| `galleryName` | String | 美术馆名称 |
| `recommendReason` | String | **推荐理由**（算法侧返回，前端可展示也可忽略） |

**失败返回**：

```json
{
  "code": 0,
  "msg": "推荐服务暂时不可用",
  "data": []
}
```

> 建议：**本接口失败时返回空数组 `[]` 而不是 `data: null`**，前端直接隐藏该区块，不影响首页其余部分。

**实现说明（方案待算法团队确定后补充）**：

- 后端职责：把 `userId` + `limit` 转发给算法接口，拿到展览 ID 列表后，回查 `exhibition` JOIN `gallery` 补全图文信息
- 未登录用户的兜底策略待定（建议：返回 `is_hot = 1` 且在展期内的展览）
- 算法接口超时应有降级，避免拖慢首页

**数据来源**：**无数据库操作**（算法接口）

## 四、获取热门美术馆列表 🔓

- **Path**：`/api/app/gallery`
- **Method**：`GET`
- **描述**：首页底部「热门美术馆」2×2 宫格

**参数**：

| 参数名 | 类型 | 必须 | 默认值 | 说明 |
|--------|------|------|--------|------|
| city | String | 否 | - | 城市筛选 |
| limit | Integer | 否 | 4 | 返回条数上限，首页传 4 正好铺满 2×2 |

**成功返回**：

```json
{
  "code": 1,
  "msg": "操作成功",
  "data": [
    {
      "id": 1,
      "name": "江苏省美术馆",
      "coverImage": "/static/mock/gallery/jiangsu.jpg",
      "address": "南京市玄武区长江路333号（总统府对面）",
      "city": "南京",
      "openTime": "周二到周日 8:30-18:30",
      "exhibitionCount": 2
    },
    {
      "id": 2,
      "name": "国立美术陈列馆",
      "coverImage": "/static/mock/gallery/guoli.jpg",
      "address": "南京市玄武区长江路266号",
      "city": "南京",
      "openTime": "周二到周日 8:30-18:30",
      "exhibitionCount": 1
    }
  ]
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | Long | 美术馆 ID，点击「查看详情」跳转用 |
| `name` | String | 美术馆名称 |
| `coverImage` | String | 封面图（**本表唯一一张图**） |
| `address` | String | 完整地址，**已含城市和区县**，前端直接显示 |
| `city` | String | 城市 |
| `openTime` | String | 开放时间 |
| `exhibitionCount` | Integer | 当前在展数量（**冗余字段**，直接读，非实时 COUNT） |

**失败返回**：

```json
{
  "code": 0,
  "msg": "系统异常",
  "data": null
}
```

**SQL**：

```sql
SELECT id, name, cover_image, address, city, open_time, exhibition_count
FROM gallery
WHERE is_hot = 1 AND status = 0
  AND (#{city} IS NULL OR city = #{city})
ORDER BY exhibition_count DESC, id ASC
LIMIT #{limit};
```

**数据来源**：`gallery` 表

**注意**：`exhibition_count` 是冗余字段，**展览增删或过期后不会自动更新**，需由应用层同步或定时任务重算（见 [db/gallery-表结构说明.md](../db/gallery-表结构说明.md)）。

## 附录五：开发注意事项

| # | 注意事项 |
|---|---------|
| 1 | 首页 4 个路径必须加入 JWT 拦截器 `excludePathPatterns`，否则返回 401 |
| 2 | 「当前热门展览」必须同时满足 `is_hot = 1` **和** 在展期内，缺一不可 |
| 3 | 展出状态（正在/即将/往期）**不落库**，由 `start_date` / `end_date` 与 `CURDATE()` 实时比较 |
| 4 | `galleryName` 通过 JOIN 获取，**禁止在循环里查数据库**（N+1） |
| 5 | 所有 `ORDER BY` 末尾加唯一列（如 `id ASC`）兜底，防止分页/排序错乱 |
| 6 | `gallery.exhibition_count` 是冗余字段，首页直接读，不要改成实时 COUNT |
| 7 | `banner.title` 页面不展示，返回它是为了后台识别，前端可忽略 |
| 8 | 「艺览智荐」接口失败时返回空数组 `[]`，前端隐藏该区块，**不影响其余 3 个区块** |
| 9 | 前端并行调用 4 个接口，不要串行等待，否则首屏会被最慢的接口拖住 |
