## 零、统一规范

### 一、响应格式

统一返回 `Result<T>`：

```json
{
  "code": 1,
  "msg": "操作成功",
  "data": {}
}
```

| code | 含义 |
|------|------|
| `1` | 成功 |
| `0` | 失败 |

### 二、分页规范

**请求**：`page`（默认 1）、`pageSize`（默认 10，最大 50）

**返回**（`PageResult<T>`）：

```json
{
  "total": 12,
  "pages": 2,
  "page": 1,
  "pageSize": 10,
  "list": []
}
```

### 三、认证规范

| 标识 | 含义 |
|------|------|
| 🔓 | 免登录可访问 |
| 🔒 | 必须带 token（登录后调用，用于返回个性化字段） |

详情页**游客也能浏览**，因此主接口用 🔓。是否带 token 会影响 `isFavorited` 的返回值：

- **不带 token**：`isFavorited` 恒为 `false`
- **带 token**：真实判断当前用户是否已收藏

以下路径需要加入 `WebMvcConfiguration` 的 `excludePathPatterns`：

```
/api/app/exhibitions/*
/api/app/exhibitions/*/works
/api/app/galleries/*
/api/app/galleries/*/exhibitions
```

> ⚠️ 详情接口用**路径参数**（`/exhibitions/{id}`），不是查询参数，白名单表达式务必写成 `/*` 而不是写具体的数字。

### 四、展览展出状态（复用统一规则）

| 状态值 | 含义 | 判断条件 |
|---|---|---|
| `current` | 正在展出 | `start_date <= CURDATE() <= end_date` |
| `future` | 即将展出 | `start_date > CURDATE()` |
| `past` | 往期展出 | `end_date < CURDATE()` |

**不落库**，由 Service 实时计算。

## 一、获取展览详情 🔓

- **Path**：`/api/app/exhibitions/{id}`
- **Method**：`GET`
- **描述**：展览详情页主体数据（头部信息 + 展览简介 + 展览实景 + 票务信息）

**Path 参数**：

| 参数名 | 类型 | 必须 | 说明 |
|--------|------|------|------|
| id | Long | 是 | 展览 ID |

**成功返回**：

```json
{
  "code": 1,
  "msg": "操作成功",
  "data": {
    "id": 1,
    "title": "咫尺千里",
    "posterImage": "/static/mock/exhibition/zhichi.jpg",
    "startDate": "2026-05-01",
    "endDate": "2026-08-02",
    "openTime": "周二到周日 8:30-18:30",
    "status": "current",
    "type": 2,
    "typeName": "当代展览",
    "description": "陆俨少是近现代山水画大家，在山水笔墨上，构筑起陆俨少一帜。本次「咫尺千里」展，汇集陆俨少手卷、册页、扇面三类小品佳作……",
    "images": [
      "/static/mock/installation/zhichi-1.jpg",
      "/static/mock/installation/zhichi-2.jpg"
    ],
    "galleryId": 1,
    "galleryName": "江苏省美术馆",
    "galleryAddress": "南京市玄武区长江路333号（总统府对面）",
    "galleryPhone": null,
    "price": 58.00,
    "totalStock": 500,
    "soldCount": 0,
    "remainingStock": 500,
    "isFavorited": false,
    "worksCount": 3
  }
}
```

### 字段说明

| 字段 | 类型 | 说明 | 对应原型区块 |
|------|------|------|-------------|
| `id` | Long | 展览 ID | — |
| `title` | String | 展览标题 | 头部大标题 |
| `posterImage` | String | 封面海报（顶部大图） | 头部背景图 |
| `startDate` / `endDate` | String | 展期，前端拼成 `05.01 — 08.02` | 头部左上方 |
| `openTime` | String | 展览开放时间 | 头部「开放时间」 |
| `status` | String | `current` / `future` / `past`，实时计算 | 控制「购票」按钮是否可点 |
| `type` / `typeName` | Integer / String | 展览分类值与中文名（如 `2` / 「当代展览」） | 头部标题下的小标签 |
| `description` | String | 展览简介长文 | 「展览简介 INTRODUCTION」 |
| `images` | Array | 展览实景图列表（库里逗号分隔，接口已拆成数组） | 「展览实景 INSTALLATION」 |
| `galleryId` | Long | 所属美术馆 ID，「江苏省美术馆」可点击跳馆详情 | 头部「江苏省美术馆」 |
| `galleryName` | String | 美术馆名称 | 同上 |
| `galleryAddress` | String | 美术馆地址 | 头部「地址：」 |
| `galleryPhone` | String | 美术馆电话（当前表无此字段，恒为 `null`） | — |
| `price` | Number | 票价（元），`0` 表示免费 | 头部右侧「¥58」 |
| `totalStock` | Integer | 总库存 | 购票页 |
| `soldCount` | Integer | 已售数量 | 购票页 |
| `remainingStock` | Integer | **剩余库存 = `totalStock - soldCount`**，由 Service 计算 | 购票页 |
| `isFavorited` | Boolean | 当前用户是否已收藏（未登录或未实现收藏时恒为 `false`） | 头部「收藏」按钮状�态 |
| `worksCount` | Integer | 作品集总数，用于判断「作品集」区块是否需要显示 | 作品集区块 |

> 📌 **「江苏省美术馆90周年系列展」这一行字原型上是在海报图片里的**，不需要后端返回。所以本接口**没有对应的字段**，前端直接展示 `posterImage` 即可。

> 📌 **`isFavorited` 当前恒为 `false`**。收藏功能对应的表已在早期清理中删除，本次只做**占位**：接口保留该字段，前端据此渲染「收藏 / 已收藏」两种状态，后端待收藏功能开发后再接。

**失败返回**：

```json
{
  "code": 0,
  "msg": "展览不存在",
  "data": null
}
```

**核心 SQL**：

```sql
SELECT e.id, e.title, e.poster_image, e.start_date, e.end_date, e.open_time,
       e.description, e.images, e.type, e.price, e.total_stock, e.sold_count,
       g.id   AS gallery_id,
       g.name AS gallery_name,
       g.address AS gallery_address
FROM exhibition e
JOIN gallery g ON g.id = e.gallery_id
WHERE e.id = #{id};
```

**Service 层要做的三件事**：

1. `images` 字段在库里是**逗号分隔字符串**，需 `split(",")` 转成数组返回
2. `status` 用 `start_date` / `end_date` 与 `CURDATE()` 实时计算
3. `remainingStock = totalStock - soldCount`

**数据来源**：`exhibition` JOIN `gallery`

## 二、获取展览作品集 🔓

- **Path**：`/api/app/exhibitions/{id}/works`
- **Method**：`GET`
- **描述**：展览详情页「作品集 / COLLECTION」区块，**独立分页**

**Path 参数**：

| 参数名 | 类型 | 必须 | 说明 |
|--------|------|------|------|
| id | Long | 是 | 展览 ID |

**查询参数**：

| 参数名 | 类型 | 必须 | 默认值 | 说明 |
|--------|------|------|--------|------|
| page | Integer | 否 | 1 | 页码 |
| pageSize | Integer | 否 | 3 | 每页条数，最大 50 |

> 原型一屏显示 3 件作品，所以 `pageSize` 默认给 **3**。

**成功返回**：

```json
{

      },
      {
        "id": 2,
        "name": "云涧水涌图（扇面局部）",
        "author": "陆俨少",
        "image": "/static/mock/work/yunjian.jpg",
        "description": "此作尽显陆俨少标志性的勾水技法，层层回旋的水涡灵动生动……"
      },

        "description": "画面以细密灵动的线条勾写潺潺水波，水纹层层叠卷……"
      }
    ]
  }
}
```

### 字段说明（对照原型卡片）

| 原型卡片元素 | 返回字段 |
|---|---|
| 左侧作品图 | `image` |
| 「作品名称：策杖行吟图（扇面局部图）」 | `name` |
| 「陆俨少」（独立一行加粗） | `author` |
| 「简介：此幅为扇面山水局部…」 | `description` |

**失败返回**：

```json
{
  "code": 0,
  "msg": "系统异常",
  "data": null
}
```

**核心 SQL**：

```sql
SELECT id, name, author, image, description
FROM exhibition_work
WHERE exhibition_id = #{id}
ORDER BY sort DESC, id ASC
LIMIT #{offset}, #{pageSize};
```

> `ORDER BY` 末尾的 `id ASC` 不能省，否则 `sort` 有重复值时翻页会出现重复记录。

**数据来源**：`exhibition_work`

**注意**：

- 作品集**不跟展览详情一起返回**，因为原型上它自己有分页控件，作品多时不能一次全返回
- 详情页需要知道「作品集区块要不要显示」→ 用接口一的 `worksCount` 判断，`worksCount > 0` 才发这个请求

## 三、获取美术馆详情 🔓

- **Path**：`/api/app/galleries/{id}`
- **Method**：`GET`
- **描述**：美术馆详情页主体数据（顶部信息 + 展馆简介）

**Path 参数**：

| 参数名 | 类型 | 必须 | 说明 |
|--------|------|------|------|
| id | Long | 是 | 美术馆 ID |

**成功返回**：

```json
{
  "code": 1,
  "msg": "操作成功",
  "data": {
    "id": 1,
    "name": "江苏省美术馆",
    "coverImage": "/static/mock/gallery/jiangsu.jpg",
    "address": "南京市玄武区长江路333号（总统府对面）",
    "city": "南京",
    "openTime": "周二到周日 8:30-18:30",
    "intro": "江苏省美术馆坐落于南京长江路文化建筑群，其前身是 1936 年建成的国立美术陈列馆，为中国近现代首座国家级美术馆……",
    "type": 1,
    "typeName": "综合美术馆",
    "exhibitionCount": 3,
    "isHot": 1,
    "isFavorited": false,
    "currentCount": 3,
    "pastCount": 2
  }
}
```

### 字段说明（对照原型区块）

| 字段 | 类型 | 说明 | 对应原型区块 |
|------|------|------|-------------|
| `id` | Long | 美术馆 ID | — |
| `name` | String | 美术馆名称 | 顶部「江苏省美术馆」 |
| `coverImage` | String | 封面图（顶部大图） | 顶部背景图 |
| `address` | String | 完整地址（**已含城市与区县**） | 顶部「地址：」 |
| `city` | String | 城市 | 顶部导航 |
| `openTime` | String | 开放时间 | 顶部「开放时间」 |
| `intro` | String | 展馆简介长文 | 「展馆简介 INTRODUCTION」 |
| `type` / `typeName` | Integer / String | 馆类型值与中文名 | 分类标识 |
| `exhibitionCount` | Integer | 当前在展数量（冗余字段） | — |
| `isHot` | Integer | 是否热门，0/1 | — |
| `isFavorited` | Boolean | 是否已收藏（**当前恒为 `false`，占位**） | 右上「已收藏」按钮 |
| `currentCount` | Integer | 「正在展出」区块的展览总数 | 分组标题右侧 |
| `pastCount` | Integer | 「往期展出」区块的展览总数 | 分组标题右侧 |

> 📌 `currentCount` / `pastCount` 用于前端渲染分组标题，也让前端知道**要不要发接口四**（为 0 则该区块不显示）。

**失败返回**：

```json
{
  "code": 0,
  "msg": "美术馆不存在",
  "data": null
}
```

**核心 SQL**：

```sql
-- ① 主体信息
SELECT id, name, cover_image, address, city, open_time, intro,
       type, exhibition_count, is_hot
FROM gallery
WHERE id = #{id} AND status = 0;

-- ② 两个分组的数量
SELECT
  SUM(start_date <= CURDATE() AND end_date >= CURDATE()) AS current_count,
  SUM(end_date < CURDATE())                              AS past_count
FROM exhibition
WHERE gallery_id = #{id};
```

**数据来源**：`gallery` + `exhibition`（仅取数量）

## 四、获取美术馆的展览列表 🔓

- **Path**：`/api/app/galleries/{id}/exhibitions`
- **Method**：`GET`
- **描述**：美术馆详情页的「正在展出 CURRENT」和「往期展出 PAST」两个区块，**同一接口靠 `status` 区分**

**Path 参数**：

| 参数名 | 类型 | 必须 | 说明 |
|--------|------|------|------|
| id | Long | 是 | 美术馆 ID |

**查询参数**：

| 参数名 | 类型 | 必须 | 默认值 | 说明 |
|--------|------|------|--------|------|
| status | String | 否 | `current` | `current` 正在展出 / `past` 往期展出 / `future` 即将展出 |
| page | Integer | 否 | 1 | 页码 |
| pageSize | Integer | 否 | 10 | 每页条数，最大 50 |

**成功返回**：

```json
{
  "code": 1,
  "msg": "操作成功",
  "data": {
    "total": 3,
    "pages": 1,
    "page": 1,
    "pageSize": 10,
    "list": [
      {
        "id": 1,
        "title": "咫尺千里",
        "posterImage": "/static/mock/exhibition/zhichi.jpg",
        "startDate": "2026-05-01",
        "endDate": "2026-08-02",
        "price": 58.00,
        "status": "current",
        "type": 2,
        "typeName": "当代展览"
      },
      {
        "id": 2,
        "title": "水印木刻",
        "posterImage": "/static/mock/exhibition/water-print.jpg",
        "startDate": "2026-05-19",
        "endDate": "2026-08-25",
        "price": 38.00,
        "status": "current",
        "type": 3,
        "typeName": "古典展览"
      }
    ]
  }
}
```

### 字段说明（对照原型卡片）

| 原型卡片元素 | 返回字段 |
|---|---|
| 上方海报 | `posterImage` |
| 「展览：咫尺千里」 | `title` |
| 「时间：05.01——08.02」 | `startDate` + `endDate` |
| 右下「¥58」 | `price` |

> 注意：美术馆详情页的卡片**没有显示美术馆名称**（因为整页都是同一个馆），所以本接口**不返回 `galleryName`**，比「全部展览」接口少一个字段。前端写卡片组件时留意这个差异。

**失败返回**：

```json
{
  "code": 0,
  "msg": "系统异常",
  "data": null
}
```

**核心 SQL**：

```sql
SELECT id, title, poster_image, start_date, end_date, price, type
FROM exhibition
WHERE gallery_id = #{id}
  <choose>
    <when test='dto.status == "past"'>   AND end_date &lt; CURDATE()  </when>
    <when test='dto.status == "future"'> AND start_date &gt; CURDATE() </when>
    <otherwise> AND start_date &lt;= CURDATE() AND end_date &gt;= CURDATE() </otherwise>
  </choose>
ORDER BY start_date DESC, id ASC
LIMIT #{offset}, #{pageSize};
```

**数据来源**：`exhibition`

## 附录五：开发注意事项

| # | 注意事项 |
|---|---------|
| 1 | 详情接口用**路径参数**，白名单要写 `/api/app/exhibitions/*`，写具体数字会失效 |
| 2 | `images` 在库里是**逗号分隔字符串**，返回前必须 `split` 成数组 |
| 3 | `remainingStock` 由 Service 算（`totalStock - soldCount`），**不要落库** |
| 4 | `status` 由日期实时算，不落库；复用与列表页相同的判断逻辑 |
| 5 | 作品集**单独接口**，不要塞进详情接口；详情接口只返回 `worksCount` |
| 6 | 美术馆详情返回的卡片**不含 `galleryName`**（整页同一个馆），与「全部展览」接口有差异 |
| 7 | 接口 3 必须带 `WHERE status = 0`，闭馆的美术馆不展示 |
| 8 | `ORDER BY` 末尾加 `id ASC` 兜底，防翻页重复 |
| 9 | **「购票」和「收藏」本次只做占位**：`price` 正常返回，`isFavorited` 恒为 `false`，两个按钮不接后端逻辑 |
| 10 | 详情页游客可看，因此主接口用 🔓；带 token 时才去查收藏状态（当前无收藏表，直接返回 `false`） |
